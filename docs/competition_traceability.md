## 按动作处理数据使用

|动作|当前处理|缺少信息实际阻塞什么|
|---|---|---|
|安全代码、合成测试、方法文档|可持续推进|不依赖全部授权问答完成|
|在现有受控本地准备获准附件|保留来源、匿名关联、缺失与版本|范围未核实则只能标为暂定，不能形成正式总体结论|
|生成学生级候选结果|是题目要求的交付准备；显式开启本地导出，忽略目录保存|真实有效标签、指标依据和可比性决定可生成内容；不因禁止公开 Git 而永久取消功能|
|向赛方指定渠道提交|题面明确要求学生级 CSV；核对实际渠道、字段与匿名标识|仅对未知提交细节待确认，不先断言题面自相矛盾|
|向协作者共享、公共/私有 Git、外部模型处理|逐一核对接收者、内容、保存条件和处理许可|没有相应依据时暂停该项传输；不阻塞纯工程工作|
