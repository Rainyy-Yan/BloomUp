# 分层标注审计资源配置模型

对应 #16，复用 #7 的样本口径和 #14 的用量记录。实现为 `challenge/allocation.py`，单学期、小规模整数穷举。它求解给定情景下的最小成本配置，不在缺真实配对与人工耗时时宣称取得正式最优方案。

## 变量与目标

将有效分析单位预先分为 H 个层，层大小 N_h，权重 W_h=N_h/ΣN_h。每层执行 m_h 次 AI 初始尝试、n_h 条独立双人复核、a_h 条裁决。当前实现固定完整预标注政策 m_h=N_h，优化 n_h，并按事先估计的分歧率 d_h 取 a_h=ceil(d_h n_h)。这是一项明确的限制：不声称联合优化模型选择、调用覆盖和复核策略，也不在模型失败后自动重试。

$$\min_{n_1,\ldots,n_H}\ C=\sum_h\left(N_hc_h^{AI}+n_hc_h^{2R}+\lceil d_hn_h\rceil c_h^A\right),\qquad n_h\in\{n_h^{min},\ldots,N_h\}.$$

c_h^{2R} 包含两名独立审阅者，c_h^A 为额外裁决成本，不能把双人复核当成一次单人时间。c_h^{AI} 是含失败尝试的单次平均成本；需要重试时应在新方案中显式修改调用/成本假设，不把失败当作免费。手工单价、耗时、模型价格及来源均须记录；未知成本返回 blocked。

## 六级、三阶与 NA

输入每层实际模型—人工配对的 6×6 计数矩阵 C_h，行是真实参照等级、列是模型等级，另给有有效人工参照但模型 NA/失败的数量 f_h。s_h=ΣC_h+f_h，六级完全一致率为 Σ_i C_hii/s_h；三阶一致率为 Σ_{floor((i−1)/2)=floor((j−1)/2)}C_hij/s_h。NA 留在分母中计作不一致，覆盖率另报 ΣC_h/s_h。人工参照本身 NA 的单位须在样本框定义阶段单列，不能混入有效等级分母。

三阶低=L1/L2、中=L3/L4、高=L5/L6；不等于 HOT=L4—L6。本求解器使用完全一致率，**不是 Kappa 的替代通过准则**；既有采用流程仍独立评估 Kappa 和覆盖。类别缺失显示 unsupported_gold_classes，不用总体均值证明稀有 L5 性能；须预先建立对应层和最低审计量，必要时追加真实样本。

## 精度界及质量约束

若未来在各层内简单随机、不放回抽 n_h 条，正确/错误指标为 [0,1] 变量，则有限总体样本均值方差满足

$$\operatorname{Var}(\bar Z_h)\le\frac{N_h-n_h}{4n_h(N_h-1)}.$$

来自有限总体修正 `(1−n/N)S²/n` 与 `S²≤N/[4(N−1)]`。以 Chebyshev 不等式、为 H 层×2 种一致率分别分配 α/(2H)，取

$$r_h(n)=\min\left\{1,\sqrt{\frac{N_h-n}{4n(N_h-1)}\frac{2H}{\alpha}}\right\}.$$

n=0 时 r=1；n=N（含 N=1）时 r=0。联合事件的失败概率上界由并集界控制，不要求六级与三阶独立。这个界很保守，尤其小层可能接近全审；不要为了减少成本偷偷换成未验证的正态近似。若实际按学生/重复组整群抽样，本公式不再可直接当作轮次级有效界，需重新定义抽样单位或扩展设计方差。

规划时把开发配对比例 p̂_h 当作未来审计均值的情景中心，定义 `L_h=max(0,p̂_h−r_h(n_h))`，约束各层六级/三阶下界、各层预测非 NA 覆盖，以及加权下界 `ΣW_hL_h≥τ`。这些 **projected lower** 是在试点可迁移假设下的预测，不是已经观察到的审计置信下界；开发样本的选择偏差、金标签错误和未来比例变化都可能破坏预测。因此即使求解成功，也不自动质量放行。

输出另给试点自身在独立代表性配对假设下的 Chebyshev 区间，暴露当前估计的不确定性。该区间不是对定向开发样本有效性的证明。未来真实抽检后必须用实际配对重新评价，不能把预测中心当作测得的审计结果；本版本不会生成 formal_recommendation=true 或 independent_audit_verified=true。

τ、各层下界、最低覆盖和人工单价均为配置决定，不预设赛题官方 Kappa 门槛。τ 未确认时只给符合层内约束的质量—成本 Pareto 前沿，不报告通过或最优正式方案。

## 求解、不可行和场景

枚举笛卡尔积 `Π_h(N_h−n_h_min+1)`，以精确 Decimal 金额比较成本，返回全枚举范围的最低成本可行情景及最多三个次优配置。同成本优先更高六级、三阶预测下界，顺序确定，无随机种子或 Monte Carlo 误差。搜索上限最多 200,000 组合；达到规模限制返回 search_limit，绝不冒称不存在可行解。

质量在该试点情景下不可达和满足质量所需费用超出预算分别输出原因。缺配对、未知成本或裁决率返回 blocked。真实参数输入只允许标 real_pilot_estimate，仍不是独立审计通过；不把单人历史标签自比当作模型配对。

```text
python -m challenge allocation-demo
python -m challenge allocation-plan --config configs/allocation.local.json
python -m unittest tests.test_allocation -v
```

`allocation-demo` 给低/中/高人工单价三种事先定义的纯合成场景，另运行较高错误率、较高 NA 率、较小/较大稀有层四种敏感性，共七种；参数随产物保存。单条人工成本等于耗时乘单价，因此同比改变耗时具有相同成本效应，不重复伪造一组独立证据。不能把这些扰动写成实测结果。只输出学期/层级聚合方案，无学生键、问题或逐条标签。

当前赛事缺独立模型—人工配对、审计设计的实际执行、人工耗时/单价和确认的目标。正式推荐配置保留 blocked；数学模型和合成求解可独立交付。该限制比把 60/240/60 个准备参数包装成最优配置更准确。
