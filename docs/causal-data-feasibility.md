# 当前数据对 B 模块目标的支持范围

对应 #9；工作范围冻结为 scope-working-v1，详见[数据登记](data-scope-register.md)。当前不能报告 AI 净学习效应，既有框架的合成验证和真实研究证据分开。此结论针对已核验文件和可读取证据，不排除补充数据后使用其他识别方法。

## 核验范围

六个工作簿已检查工作表结构和列名，两期问答、四份名单及秋季使用次数已重算对账。本轮进一步提取七份 DOCX 的主文档文字并定向检查“前测、后测、考试成绩、对照组、采用时序”等相关段落。七份文档均未含 Word 原生表格，主要为课程反馈、智能体使用讨论和知识案例。

关键词不能当成变量：核查到的“前测”属于学生建议按课前测试定制内容；“对照组”属于讨论如何验证注意力机制的例子；“成绩”包括课程评分说明和教学例题。它们不能直接转换为本批学生的独立前后测或处理对照。课程反馈也不能在未经测量验证时替代独立学习结果。

DOCX 中还包含大量嵌入图片；本轮没有全面 OCR、追踪外链或核对教师成绩系统。因此准确结论是“尚未取得可用于该目标的结果/处理设计数据”，不是“所有可能来源都不存在”。原文和段落索引留受控工作区，公开文件仅保留结论与读取边界。

## 目标、字段与可支持结论

|目标|当前字段/证据|适用条件与缺口|现在可交付|
|---|---|---|---|
|描述日志使用情况|学期、时间、渠道、问答记录、匿名键；秋季有工具类型及计数|选择范围暂定；没有日志者与无使用者并不自动等价|845/393 条候选记录、297/107 个观察到的匿名 ID，春季名单 132 人；仅过程覆盖|
|原始对话首末 HOT 变化 Δ_obs|轮次和原始端点可定位；独立有效标签尚缺|需真实语义准入、冻结标签；学生等权，学期内相关组 bootstrap；覆盖范围限定已准入且端点可用者|当前数值缺失，不用模型 12 条探索标签补正式观察表|
|AI 学习方案对采用者的 ATT|当前没有确认的独立学习结果、可解释处理/比较组及共同起点|一致性、无预期、条件平行趋势、重叠及干扰处理须针对真实设计论证|effect=null，目标研究受阻；提供增补字段清单|
|重复横截面的 DID|两学期数据存在，但量尺/构成/处理定义未建立|需要各期处理/比较样本、相同结果量尺和可辩护构成假设，不必强求同一学生|不能仅凭不同学期均值构造 DID；现有实现也未支持此设计|
|回归不连续/工具变量/随机试验|没有已核实阈值规则、外生工具或随机分配记录|必须有对应设计证据及排除/连续性等条件，不能凭方法名称补出|暂跳过；待真正设计记录后决定是否扩展实现|
|异质性或跨学期效应比较|春季 Agent 身份未知，跨期匿名语义未知|分层须为处理前变量；量尺、课程、工具机会和人群须可比|不把渠道分组当 Agent 效应，不拼未经核实同人面板|

## 最小追加数据及用途

|优先级|需要的受控字段/说明|用途|
|---|---|---|
|P0|同一量尺的独立学习结果、测量规则、测量时间及缺失原因|定义 Y，区分认知请求、学习能力和自报体验|
|P0|AI 干预/比较条件定义，实际分配或采用时间，暴露及依从记录|定义 D 与时间，区分处理前后、采用者 ATT 与分配 ITT|
|P0|目标总体、正式名单、匿名关联规则；按拟选设计给出必要关联|避免错误拼接，确定同人面板或重复横截面，不索取可识别真人信息|
|P1|处理前能力、课程/教师/班级和专业等预先声明协变量|支持混淆控制、分层和聚类推断，不能事后按效果挑选变量|
|P1|更多处理前结果，或随机/阈值/工具分配过程记录|按实际可行设计检查趋势或替代识别；不是所有方法一律要求同份字段|
|P1|差异退出、缺测、交叉使用和同伴共享记录|评估选择、污染、干扰及结果适用范围|

获得数据后先冻结目标、协议、主要结果、分层和敏感性范围，再查看效应。单靠负责人填 assumed 不解除证据缺口。按用户“确实解决不了的跳过”的指令，本轮跳过真实净效应估计与缺标签的 Δ_obs，不伪造对照、成绩或显著性；保留 B 实证未完成状态。

## 现有工程覆盖与边界

复用 `tests/test_causal.py` 和 `test_causal_workbench.py`：已知/零效应、构成混淆、时间顺序、缺对照、共同支持、少簇、簇复制、bootstrap 失败、假设违背反例、平衡诊断、阻断 CLI 与报告。无需为相同缺口再写一个估计器。合成运行回执、命令、退出码和代码指纹纳入当前进度回执；历史模拟数值只标其原运行版本，不冒充新真实结果。

历史 T3 的“15 段、14 人、12/14”等结果尚未取得当前工作区中的可复核原标签产物，不能作为本轮真实统计输入。真实结果表此时只能标 NA 及具体原因；合成已知效应另表展示。
