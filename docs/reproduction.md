# 离线复算与红队证据

对应 #12。入口复用当前 challenge 包，不复制第二套数学实现。无需赛事附件、模型密钥或网络即可运行：

```text
python -m pip install -r requirements.txt
python -m challenge --root .ci-state/reproduction reproduce
```

已有依赖时跳过安装。测试还需要可用的 Git 命令，源码包本身不需要 .git；忽略规则在测试临时仓库内验证。Windows 可用 `./run_all.ps1 -PythonPath <已有解释器>`；Unix 可用 `sh run_all.sh`，环境变量 PYTHON 可指定解释器。运行会执行全部合成测试、受控运行器的合成链路、合成学生表导出、两个独立合成 B 场景、资源配置情景与八类红队，并验证产物依赖树。默认不读取真实文件，不调用付费 API。

输出根目录含 `reproduction-result.json`、测试日志和 `reproduction_aggregate/` 下聚合 CSV。全部逐条合成夹具显式标识；不能把它们并入真实研究。回执记录代码指纹、依赖、耗时、退出码与尚缺证据。源码包在新解压目录运行只能证明同机独立目录复算；只有另一位实际审阅者执行并回传环境/命令/耗时后，才可写“第三方完成”。

## 八类攻击的验收范围

|攻击|本轮可执行范围|解释边界|
|---|---|---|
|R01 AI 答当学生能力|替换当前 AI 答，检查解析后的当前学生输入不变|只验证解析结构，不证明模型语义鲁棒性|
|R02 伪高阶词|保留攻击设计及 NA 记录|未用冻结模型和独立参照执行，不把提示词文字当作通过|
|R03 复制/外包高阶请求|固定合成标签，比较请求分数与掌握程度无法区分的反例|FAIL 针对把过程分数解释为掌握能力，不是实测模型错误率|
|R04 重复灌水|增加重复高阶轮次，实际调用评分入口观察 HOT|保留分母操纵的 FAIL，不静默去重或改公式|
|R05 拉长/循环对话|插入循环中间轮次，核查原始端点 CTQ 不变|PASS 仅对 CTQ，其他比例指标可能变化|
|R06 刷工具|固定目录内增加不同工具身份，调用 MAB 计算|没有实质使用核验时 MAB 仍可升高，保留 FAIL|
|R07 学期/名单混入|实际运行合成工作簿的范围排除回归|只验证既定筛选，不确认真实教学日期|
|R08 数据/标签泄漏|实际验证同人和长精确重复组不跨池|语义近重复与内嵌标签诱导未验证，整类为 BOUNDARY|

FAIL 是研究反例，应在论文局限中展示，不等于运行命令失败。测试未通过或脚本异常仍单独返回非零码。当前结果来源与历史“3 个 FAIL”的原始产物并未建立等价关系；即使数量相同，也不声称重现历史实验。各项的输入来源、执行状态、攻击数量、观测变化和说明均进入聚合 red_team 产物。

## 真正的赛事结果复算

授权数据由每个研究者在包外自行提供，不随源码 ZIP 传播。真实路径为现有 prepare / dataset-import / 人审 / prediction-import / quality-evaluate / labels-freeze / metrics-compute / report-build；详见[操作指南](workflow.md)和[运行器说明](inference.md)。复算已缓存标签与再次付费推理是不同动作，run_all 不触发后者。

未取得旧记录级与轮次级人工标签的原件、版本和出处，因此不硬编码旧 100/55 分布为预期答案。当前真实 Δ_obs、bootstrap 区间、三方案 AIV 和跨期效应不能复算，聚合样例都加 synthetic 前缀。当前没有足够证据证明完整赛事真实核心结论能在 30 分钟内复算。

## 包核验

源码包采用逐文件清单，只含通用代码、合成测试、无密钥模板、方法文档和运行入口；不打包 Git 历史、work、local_state、.ci-state、原始工作簿、人工标注、模型原始返回或机器配置。符号名如代码中的 student_key 是字段定义，不是实际学生标识；不允许以字段名检查替代真实数据泄漏检查。

打包清单记录每个源文件 SHA-256。在新目录解压后先核验，再离线运行。最终赛事专用学生结果表使用另一个经核验的受控渠道，不能把源码 ZIP 变成原文或学生结果传播包。
