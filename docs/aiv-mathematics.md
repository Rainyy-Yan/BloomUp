# AIV v2：定义、性质与实现边界

本规范是赛题一综合评价模块的可复算候选模型。它描述已准入、已观察到的提问认知需求与工具使用广度，不测量独立学习能力，不识别 AI 的净因果效应。数学性质不构成教育效度证据。默认参数均为待验证选择；合成演示不是比赛实验结果。

## 1. 样本、符号与冻结条件

在固定学期中，以学生为单位。令有效标签数为 $N$，等级计数为 $n_k$，$k\in\{1,\ldots,6\}$。

$$p_k=\frac{n_k}{N},\quad p\in\Delta_6=\{p\ge0:\sum_{k=1}^6p_k=1\}.$$

仅当 $N>0$ 时定义 $p$。NA 不编码为某个等级，也不进入分母；覆盖率另报。课程参考分布 $q$ 必须满足 $q_k>0$、$\sum_kq_k=1$。等级效用 $u$ 满足

$$0=u_1<u_2<\cdots<u_6=1.$$

默认 $u_k=(k-1)/5$ 是等距假设，不意味着 Bloom 序数天然具备等距尺度。ABL 仍仅为平均等级的辅助描述，不进入 AIV。配置冻结 $u,q$、参考依据与状态、DHI 模式、惩罚系数、Agent 目录与状态、权重和合成函数；改变任一项产生新的内容版本。

当前模板 $q=(0.10,0.20,0.25,0.25,0.15,0.05)$ 是尚无课程实证支撑的候选目标。使用前应给出课程目标、教学任务或独立专家依据，不能根据本批排名反向选择目标再宣称已验证。目录也不能由本批学生用过的 Agent 联集自动估计。

## 2. 四个基础指标

### HOT：高阶需求比例

$$H=\sum_{k=4}^{6}p_k\in[0,1].$$

无有效标签时缺失。该比例条件于现有标签，不自动代表所有提问的高阶比例。

### CTQ：原始对话净变化

对原始多轮对话 $c$，长度 $T_c\ge2$，原首末轮均有标签时，定义

$$\delta_c=u_{\ell_{c,T_c}}-u_{\ell_{c,1}},\qquad C_c=\frac12+\frac12\delta_c.$$

学生 CTQ 为所有符合条件的原始对话的等权均值 $C=|\mathcal C|^{-1}\sum_{c\in\mathcal C}C_c$。空集合时缺失。单轮对话不赋中性分；首末轮缺失时不以内部轮次替代。中间标签缺失不阻断已知首末净差。

**范围和方向。** $-1\le\delta_c\le1$，故 $0\le C_c\le1$；上升、持平、下降分别对应大于、等于、小于 $1/2$。

**分段复合。** 若连续分段边界 $1=t_0<\cdots<t_m=T_c$ 均已观察到，则望远镜求和给出

$$\sum_{j=1}^{m}(u_{\ell_{c,t_j}}-u_{\ell_{c,t_{j-1}}})
=u_{\ell_{c,T_c}}-u_{\ell_{c,1}},$$

$$C_c=\frac12+\sum_{j=1}^{m}\left(C_{c,j}-\frac12\right).$$

这里是中心化分段分数的求和复合，**不是任意拆段后取算术平均**。分段必须保留原始对话身份；跨对话重新分组不满足此性质。全部中间轮有标签时，也可用逐轮效用差求和表示。CTQ 仅测净变化，序列 $2\to6\to2$ 与 $2\to2$ 都为 $1/2$，不评价振荡或过程质量。

### DHI：与目标分布的归一化接近度

令总变差距离 $V(p,q)=\tfrac12\sum_k|p_k-q_k|$。对称指标为

$$D_{\rm sym}(p;q)=1-\frac{V(p,q)}{1-\min_kq_k}.$$

**归一化证明。** 因 $p=\sum_rp_re_r$，距离关于 $p$ 凸，

$$V(p,q)\le\sum_rp_rV(e_r,q)\le\max_rV(e_r,q)=1-\min_rq_r.$$

最小 $q_r$ 对应的顶点达到上界。因此 $D_{\rm sym}\in[0,1]$，$D=1$ 当且仅当 $p=q$，且最远顶点达到 $D=0$。旧版 $1-V(p,q)$ 的最小值为 $\min q_k>0$，不能把两版分数直接混用。

为区分不足与过量，冻结 $a_k>0,b_k>0$，定义

$$L(p;q)=\sum_k\big[a_k(q_k-p_k)_++b_k(p_k-q_k)_+\big],\quad (z)_+=\max(z,0),$$

$$M(q,a,b)=\max_r\left[\sum_{k\ne r}a_kq_k+b_r(1-q_r)\right],$$

$$D_{\rm asym}(p;q,a,b)=1-\frac{L(p;q)}{M(q,a,b)}.$$

**证明。** $L$ 非负、关于 $p$ 凸，且 $L(e_r;q)$ 恰为方括号内的表达式。由相同凸组合论证，$\max_{p\in\Delta_6}L=M>0$。正系数保证 $L=0\iff p=q$。因此非对称 DHI 同样满足上述范围、目标唯一性和极端可达性。两组惩罚都为 1 时，$L=2V$、$M=2(1-\min q)$，回到对称公式。全部惩罚同倍缩放不改变结果。

固定方向 $p(t)=(1-t)q+tp$，$0\le t\le1$，有 $L(p(t);q)=tL(p;q)$，所以离开目标的同向偏差增大时 DHI 单调下降。DHI 衡量接近课程目标，不保证随高等级占比增加而上升；高阶过度集中也可能偏离目标。

### MAB：Agent 使用广度

令 $\mathcal A$ 为事先冻结、比较对象共同可用的 Agent 目录，$K_{\max}=|\mathcal A|\ge1$，$K$ 为学生全部已准入轮次中实际使用的不同 Agent 数。

$$B=\frac{\log(1+K)}{\log(1+K_{\max})},\qquad 0\le K\le K_{\max}.$$

故 $B(0)=0$、$B(K_{\max})=1$，且

$$B'(K)=\frac1{(1+K)\log(1+K_{\max})}>0,\quad
B''(K)=-\frac1{(1+K)^2\log(1+K_{\max})}<0.$$

离散增量也递减。标签缺失不影响已知工具使用记录；但目录未知或任一准入轮的 Agent 身份未知时，MAB 缺失。目录外 Agent 直接阻断，不截断计数。无准入轮次者不推定 $K=0$，全部指标保持缺失。不同课程的可用机会、任务数量或工具功能不一定可比，除以目录规模不能消除此偏差。MAB 不衡量使用质量，不能鼓励为加分而切换工具。

## 3. AIV 合成、三种方案与性质

令 $x=(H,C,D,B)\in[0,1]^4$，$w_j\ge0$、$\sum_jw_j=1$。

$$A_w^g(x)=100\sum_{j=1}^4w_jg(x_j).$$

线性取 $g(x)=x$。边际递减取

$$g_\rho(x)=\frac{1-e^{-\rho x}}{1-e^{-\rho}},\quad \rho>0.$$

|预设方案|权重 HOT / CTQ / DHI / MAB|合成函数|
|---|---|---|
|high_order_linear|0.50 / 0.30 / 0.15 / 0.05|线性|
|balanced_linear|0.30 / 0.30 / 0.30 / 0.10|线性|
|diminishing_returns|0.50 / 0.30 / 0.15 / 0.05|$g_1$|

三种方案是预设敏感性候选，不是从实证拟合得到的最优方案。`primary` 使用配置中的权重和函数，默认与 `high_order_linear` 相同；重复展示便于对照，不能把它算作第四种独立方案。

**有界与端点。** 两种函数均把 $[0,1]$ 映射至 $[0,1]$ 且 $g(0)=0,g(1)=1$，因此 $0\le A\le100$，四指标全零、全一时分别为 0、100。这是指标空间上的性质，不承诺真实学生数据能同时达到所有端点。

**单调。** $g'(x)>0$，所以 $\partial A/\partial x_j=100w_jg'(x_j)\ge0$；权重为零时不严格增加。这里针对四指标坐标，不是针对原始 Bloom 标签的逐项单调性，因 DHI 同时惩罚偏离目标。

**边际递减。** $g_\rho''(x)=-\rho^2e^{-\rho x}/(1-e^{-\rho})<0$，故在正权重坐标上严格凹；线性方案的边际恒定。对相同输入 $g_\rho(x)\ge x$，所以非线性方案的分数通常高于线性方案，这源于标尺选择，不能解释为学习改善。

**特征扰动界。** 设 $x,y\in[0,1]^4$，线性时 $L_g=1$，非线性时 $L_g=\rho/(1-e^{-\rho})$。中值定理和三角不等式给出

$$|A_w^g(y)-A_w^g(x)|\le100L_g\sum_jw_j|y_j-x_j|.$$

这界定已得到的指标扰动，不自动把“标签错误概率”转换为分数误差概率。实际标签扰动仍须通过同一公式重新计算。

**权重扰动界。** 对同一 $g,x$ 和两组单纯形权重 $w,v$，令 $d=w-v$。因 $\sum_jd_j=0$，有

$$\left|\sum_jd_jg(x_j)\right|\le\sum_{d_j>0}d_j=\frac12\|w-v\|_1,$$

$$|A_w^g(x)-A_v^g(x)|\le50\|w-v\|_1.$$

此界不适用于同时更换合成函数的比较，程序在那种情形输出空值。每个权重分别乘以 0.9、1.1 后归一化：

$$v_j=\frac{w_jm_j}{\sum_kw_km_k},\quad m_i\in\{0.9,1.1\},\quad m_{j\ne i}=1.$$

这是乘法扰动后再归一化，最终权重不一定恰好相差 10%；零权重仍为零。

## 4. 缺失指标的条件外界

令 $O$ 为已观察指标集合。固定其数值，其他指标仅知属于 $[0,1]$：

$$A_{\rm lo}=100\sum_{j\in O}w_jg(x_j),\qquad
A_{\rm hi}=A_{\rm lo}+100\sum_{j\notin O}w_j.$$

端点来自 $g(0)=0,g(1)=1$；该范围覆盖所有矩形补全，不对已有权重重新归一化。只要存在正权重缺失指标，就不输出 AIV 单值。零权重缺失指标不影响分数。

指标间受数据结构约束，矩形补全端点未必能共同实现，因此这是一组保守条件外界，不声称是锐识别区间。为兼容既有存储字段仍命名 `identification_bounds`。范围固定已观察标签和可用原首末轮导出的指标，不涵盖全部缺失标签、准入选择偏差、抽样误差或真实学习能力；不是置信区间。无准入轮次的清单学生保持整行缺失，不输出形式上的 `[0,100]`。

例如 $x=(0.6,\mathrm{NA},0.8,\mathrm{NA})$，主权重线性方案有 $A_{\rm lo}=42$、$A_{\rm hi}=77$；程序不能把该样本偷偷变为 HOT/DHI 两项总分。

## 5. 比较、扰动与报告约束

`analysis-sensitivity` 在每学期使用同一批四指标完整学生，输出主方案、上述三种方案及 8 个权重扰动情景，共 12 行/学期。排除人数显式保留，即使主方案给某缺失指标零权重，也不把该样本加入其他方案的共同比较。

报告给出平均分、相对主方案的最大绝对分差、同函数权重理论上界、平均秩 Spearman 相关及六对基础指标相关。完全相等的数值用平均秩；少于两人或任一列常量时相关未定义，输出空值，不伪造相关系数。计算按学期分开，不把不同机会下的学生混排；产物不发布个人名次或学生键。相关性用于检查方案敏感性和重复信息，不证明公平性或有效性。

`analysis-label-sensitivity` 在每次扰动中调用同一冻结 `spec`，同步更新 HOT、CTQ、DHI、AIV；Agent 使用证据固定，MAB 不受标签噪声影响。已有缺失保持缺失。0%、10%、20%、30% 是假设错误质量，不是已估计错误率。模拟范围和相关组重抽样范围保留原有解释边界。

## 6. 实现、复算与后续证据

- `challenge/scoring.py`：纯公式、域验证、单指标性质和理论界。
- `challenge/metrics.py`：原始对话分组、可用标签口径、版本调度和缺失传播。
- `challenge/comparison.py`：学期内共同样本与聚合相关分析。
- `tests/test_scoring.py`：端点、非对称归一化、分段复合、单调、凹性、稳定性及缺失界。
- `tests/test_scoring_workflow.py`：版本差异、未知目录、首轮缺失、合成完整流程和零扰动复算。

`configs/metrics.v1.json` 保持原三指标公式；`configs/metrics.v2.json` 显式标识 `aiv-v2`。CLI `demo` 默认 v2，`demo --formula-version legacy-v1` 可复算旧流程；Python `run_demo(root)` 保持历史默认 v1，避免改变旧调用者行为。新演示仅用已声明的一个合成 Agent 目录；实际模板目录为 null，未经配置不生成 MAB 或完整 AIV。

数值实现使用 `expm1` 和 `log1p`。实现限定 $0<\rho\le50$；数学结论适用于任意正 $\rho$。参考、权重按既有单纯形容差验证；仅对舍入误差做端点裁剪。非对称惩罚先同比缩放，极端动态范围导致正系数下溢时拒绝计算。浮点性质检查使用数值容差。

尚需真实授权数据、独立标注质量、课程目标与 Agent 机会依据、外部学习结果验证，才能讨论教育解释。当前实现没有选择“最优”权重，没有真实学生实验结论，也没有完成因果识别模块。
