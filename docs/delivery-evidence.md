## E 模块的解释与治理原型

学生视图展示自己的有效轮次覆盖、HOT/CTQ/DHI/MAB 含义、缺失原因和版本；默认不展示跨学期名次，不把请求复杂度当作已掌握能力。教师视图展示课程内覆盖、哪些对话端点缺失、任务请求构成和需复核的外包情形；教学建议应由教师结合真实作业/表现判断。管理者视图展示数据来源、授权渠道、缺口、费用、质量审查和复算状态，不展示学生原文或个体排名。

跨群体校准先核对任务机会、课程目标 q、Agent 目录、标注规则、缺失机制和结果量尺；必要时用共同锚定任务与独立盲审检验一致性。未建立可比性前分别报告，不能仅归一化分数就宣称跨学期公平。当前只交付框架，不声称校准已经验证。

数据治理保持原始资料只读、内部匿名关联和分渠道授权，模型调用与人工采用分开记录，旧快照及失败不覆盖。学生表仅在显式开启的受控本地产生；向赛方提交、协作者共享与 Git 发布分别核对。
