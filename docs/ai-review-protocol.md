# AI 参考复核协议 v1（2026-09-27）

用户明确授权由 AI 接替本项目当前的人工审查工作。执行者为 Codex AI；本协议产物命名为 `ai_reference`，不写入空白的人审 CSV，不生成 `gold`，不声称真人、双人独立、盲审或准确率金标准。原有人工路线和质量门槛保留。

## 分析对象和规则

分析对象是当前学生话语**向 AI 请求的任务**。前文仅帮助解释指代，不把 AI 话语或对学生的表扬作为等级依据。学生回答 AI 问题、表示理解、选择兴趣方向也有教学价值，但不等于当前向 AI 提出的任务；在本构念下记 NA，并说明原因。NA 不等于低能力、不学习或垃圾数据。

六级沿用标注手册：L1 识别/列举/定义/复述；L2 解释/因果与关系；L3 在具体题目应用已知方法；L4 分析结构、机制、条件和差异；L5 按明确标准评判；L6 构造新方案。三阶为 L1–2、L3–4、L5–6，HOT 仍为 L4–6。

本次开发复核统一以下歧义规则，属于查看开发样本后的协议细化，不是预注册独立验证：

- 仅有主题或课程标题，没有可辨识请求动作：NA；不得靠 AI 后续回答反推请求。
- 泛化“介绍”但未要求解释机制或推导：按基本概念概述记 L1，保留 L1/L2 歧义备注。
- 比较方法优劣但未给评价标准：主要任务按 L4；没有标准时不自动升 L5。
- 短追问明确要求 AI 回答上一问题：结合紧邻前文判请求，不能仅因短或外包而 NA；引用仍取当前文本。
- 要求列出应学习的知识点：L1；没有明确要求构造新学习方案时不自动升 L6。
- `outsourcing` 与等级分开；明确“直接给答案”等记 yes，无法确认独立完成要求时 uncertain。自报置信度不是校准概率。

## 当前复核方法

本次 14 条开发样本：当前话语逐条阅读，上下文用于角色和指代核对；长上下文核对紧邻尾部，未承诺重新完整阅读所有长历史。已接触历史预测汇总，故登记 `context_exposed`，不宣称盲法。具体引文、理由和主观置信度留在受控本地。相同条目在旧提示词 v1、v1.1 及新 v2 候选任务中分别绑定版本，不覆盖原始预测。

## 可复算合同

```powershell
python -m challenge --root PRIVATE_STORE ai-reference-import --task TASK_ID --file PRIVATE_REVIEW.json --protocol docs/ai-review-protocol.md
python -m challenge --root PRIVATE_STORE ai-reference-compare --predictions PREDICTIONS_ID --reference AI_REFERENCE_ID
```

输入 JSON 顶层为 `task_id, reviewer, reviewed_at, exposure, rows`；每行严格使用 prediction 合同字段，ID 集合须精确匹配任务，引文须属于当前问题。协议全文随内容寻址产物保存。

比较报告分开列出：双方 NA、仅参考 NA、仅预测 NA、双方有等级；六级与三阶仅使用双方有等级的同一配对分母，称一致率，不称预测准确率。NA 多时不可把双方 NA 当作正确率来夸大表现。没有独立抽样/标签误差依据，不生成总体质量区间、正式成本最优推荐或实测误差传播。

`quality-evaluate` 仅接收 `gold`，会拒绝 `ai_reference`；一致率达到 1 也不改变该边界。AI 复核可解除“没人填写开发反馈”的执行障碍，不能确认正式名单、教学日历、课程参考分布或不存在于日志的学习结果。
