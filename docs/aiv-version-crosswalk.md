# AIV 公式版本与受控结果表

对应 #11，基于 `challenge/metrics.py`、`scoring.py`、`comparison.py` 和 `configs/metrics.v1.json` / `metrics.v2.json`。版本由指标产物显式记录，配置指纹固定 q、效用、目录、权重和聚合函数；历史结果不得静默改公式后混列。

令 p 为有效认知标签的六级频率，q 为事先确定的课程目标分布，u 为递增效用，k 为使用的不同 Agent 数，K 为冻结的可用目录大小。

|项|legacy-v1|aiv-v2|迁移条件|
|---|---|---|---|
|HOT|有效标签中 L4—L6 占比|相同|同一标签、分析单位和缺失范围；三阶分类中的“高=L5—L6”不是 HOT|
|CTQ|每个可用对话 `1/2+(L末−L首)/10` 后等权平均|每个可用对话 `1/2+[u(L末)−u(L首)]/2` 后等权平均|只有 `u(l)=(l−1)/5` 时等价；必须使用原始首末轮，单轮或端点缺失为 NA|
|DHI 对称|`1−V`，`V=Σ|p−q|/2`|`1−V/(1−min(q))`|不等标度；同 q 才有 `DHI_v2=(DHI_v1−min(q))/(1−min(q))`；v2 要求 q 各项大于 0|
|DHI 非对称|旧主评分不使用|`1−d(p,q)/max_r d(e_r,q)`；d 为各等级短缺/过量正罚权之和|罚权与 q 必须一同固定；所有罚权统一倍乘不改变得分|
|MAB|附加描述值 `min(k,3)/3`，不进入三分量 AIV|`log(1+k)/log(1+K)`，进入四分量 AIV|需完整 Agent 身份和真实可用目录；未知为 NA，目录外身份报错；不能以问答渠道或本批使用并集代替目录|
|AIV|`100Σw_j x_j`，三分量 HOT/CTQ/DHI|四分量 HOT/CTQ/DHI/MAB，可线性或凹变换|默认 v1 权重 .5/.3/.2，v2 .5/.3/.15/.05；分量或聚合不同不可直接比较历史分值|

v2 的凹函数为 `gρ(x)=(1−exp(−ρx))/(1−exp(−ρ))`，ρ>0；AIV 为 `100Σw_j gρ(x_j)`。HOT、CTQ、DHI、MAB 在适用合同下取 [0,1]，AIV 取 [0,100]。CTQ 衡量原始首末认知需求差，不解释为路径持续上升；中间先升后降可能净变化为零。DHI 衡量与目标的接近程度，不是越高阶越高分。

v2 正权重分量缺失时保留 AIV=NA，只给固定已知分量的条件上下界，不把缺失权重重分配；零权重分量可以不参与该单一方案评分，但跨方案排名仍使用完整四指标共同人群。这些边界不是置信区间，也不覆盖全部缺失标签的不确定性。

## 三方案和敏感性

复用 `scheme_definitions`：高阶优先线性 (.5,.3,.15,.05)、均衡线性 (.3,.3,.3,.1)、高阶优先凹聚合 (ρ=1)，另列当前主配置为 baseline。旧研究所述熵权缺失不能由这三种预设冒充。所有方案按学期固定同一完整人群，不补不同学生来凑数字。权重敏感性逐项乘 0.9/1.1 后重新归一，总计八个扰动；同变换下最大分差界为 `50||w−v||₁`。

q 当前仍为待领域确认的预置假设，真实 v2 配置中的目录为 null。春季问答没有 Agent 身份字段。当前没有冻结有效真实标签，因此真实三方案结果仍 blocked；合成测试只能验证计算。冻结工作口径见[数据登记](data-scope-register.md)，并未把这些缺失事实变成已知。

## 显式启用的本地导出

```text
python -m challenge --root local_state student-export --metrics <metrics-id> --enable-student-output
```

无开关则拒绝。只在该状态根目录 `exports/<unique>/student-results.csv` 生成内部表；默认 local_state 已忽略，自定义 root 须确认受控。表记录匿名键、学期、数据/标签/指标 ID、公式与配置指纹、参考/目录/范围状态、四指标、条件边界、标签覆盖、缺失原因、排名人群及解释边界。没有原文或模型理由。另生成带 CSV 哈希的内部回执，不自动发布或发往赛方。

每人输出 baseline 和三方案四行。排名限定学期内共同完整人群，降序并使用精确同分的平均名次；不对分数提前舍入。同分并列的 Top quartile 以第 ceil(n/4) 个降序分数作阈值，边界同分全部纳入，因此人数可能超过四分之一。缺失者保留空名次；全体同分时相关系数为 NA，不伪造稳定性证据。

原始名单中没有候选记录的学生仍只进入来源总人数，本表不重建其个人标识。若正式提交要求完整名册逐人占位，需另有授权同版名册及明确关联合同后再扩充；当前表不能宣称覆盖这部分个人。所有结果状态保持 synthetic 或 exploratory，只有具备独立质量、课程依据和提交条件后才能形成正式结果。
